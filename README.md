# AgentSessionizer

> **This repository has moved to Apache SkyWalking.**
>
> Development continues as **Apache SkyWalking AI Sessionizer**:
> **https://github.com/apache/skywalking-ai-sessionizer**
>
> Further updates, issues and pull requests belong there. This repository is
> kept only as the snapshot that was donated, and receives no further changes.

AgentSessionizer was the personal project this work grew from: conversation-level
observability for long-lived AI agents. It assembles fragmented agent telemetry -
transcripts, subagent streams, workflow journals - into one durable conversation
structure.

The same tree, with the ASF module path and license headers, is the first commit of
the Apache repository. Container images are published from there to
`ghcr.io/apache/skywalking-ai-sessionizer`.
